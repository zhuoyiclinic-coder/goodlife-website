醫美診所至少要處理客戶預約、結帳與收據發票、套票儲值、業績抽成、耗材庫存、會計報表；有健保門診再加健保申報。重點是資料要連在一起。

## 一間醫美診所每天會碰到哪些作業？

從客人預約進門，到月底結帳，大致會經過下面這些環節。每一項都可以問自己：現在用什麼做？會不會重複輸入？

| 作業 | 主要使用者 | 要檢查的重點 |
|---|---|---|
| 預約與客戶資料 | 櫃台、諮詢師 | 客戶資料只有一份，不同人看到的是同一份 |
| 諮詢與報價 | 諮詢師 | 報價、折扣有沒有紀錄 |
| 結帳收款 | 櫃台 | 一筆單能否同時有療程和商品 |
| 醫療收據／電子發票 | 櫃台、會計 | 醫療勞務與商品是否分開開立 |
| 套票與儲值 | 櫃台、會計 | 剩餘堂數、餘額能即時查 |
| 業績與抽成 | 店長、會計 | 一張單多人分業績、退費怎麼扣 |
| 耗材庫存 | 護理、庫管 | 照療程扣量，記批號與效期 |
| 會計傳票 | 會計 | 收款能否直接變成傳票 |
| 薪資 | 行政、會計 | 底薪、抽成、手技費能否合併算 |
| 報表 | 老闆 | 每天能看到收款與預收餘額 |
| 健保申報 | 有健保門診者 | 需要能申報健保的 HIS |

## 哪些是法規一定會碰到的？

醫療法第 22 條要求收取醫療費用要開給載明項目及金額的收據；如果診所也賣保養品等商品，商品部分要依營業稅規定處理，達一定銷售額就要開統一發票。病歷依醫療法第 70 條至少保存七年。客戶資料屬個人資料，健康與醫療資料在個資法上保護更嚴格。

## 用很多套工具會有什麼問題？

最常見的是同一筆收款要打三次：收銀一次、Excel 業績一次、會計再一次。任何一處改了金額，其他地方就對不起來。月底對帳時，花最多時間的通常不是計算，而是找出哪裡不一致。

## 怎麼排優先順序？

1. 先看收款：結帳、收據發票、套票儲值，這是每天都在發生的事。
2. 再看人：業績抽成和薪資，影響員工信任。
3. 最後看貨和帳：耗材庫存、會計傳票和報表。
